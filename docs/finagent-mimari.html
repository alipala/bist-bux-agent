3

Deterministik katman — LLM yok

Sahip başına: vadesi dolan tahminleri puanla, tarayıcıyla sinyal üret (portföy + izleme + likidite süzgeci), tez kontrolü, portföy riski (yoğunlaşma, açık zarar). Makro panel (altın, petrol, kur, faiz, VIX) bağlam olarak yanına konur — sinyal üretilmez, al/sat çıkmaz. Sayılar burada hesaplanır; model bunları alır, üretmez.
